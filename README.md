# Drone Catcher

Офлайн-аркада для Android в горизонтальном режиме. Удерживайте кнопку у края экрана, чтобы двигаться и ловить падающие дроны. Цель раунда — 25 поимок.

## Установка

- Android 8.0 или новее.
- Откройте репозиторий **MaximusStalsky/drone-catcher** в GitHub Store / Komi Store и установите APK из последнего релиза.
- [Последний релиз](https://github.com/MaximusStalsky/drone-catcher/releases/latest)

В игре есть пауза, настройки громкости, три 8-битные аранжировки «Калинки» Ивана Ларионова, аркадные эффекты и голосовые реплики. Дополнительная тема — [Overworld Theme от Louswan](https://opengameart.org/content/overworld-theme-0), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
